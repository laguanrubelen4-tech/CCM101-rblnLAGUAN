
# Reflection

In this laboratory activity, I learned how `docker-compose.yml` can make a cloud engineer’s work easier. Instead of typing many Docker commands one by one, we can put the needed settings in one file. With Docker Compose, we can start several containers using just one command. This saves time and makes the deployment easier to manage.

I also learned that YAML files need proper indentation. If I use a Tab instead of spaces or put the spaces in the wrong place, the file can show an error. When this happens, Docker Compose may not run properly. This taught me to be careful when writing the Compose file because even a small mistake can affect the whole deployment.

We used environment variables such as `MYSQL_PASSWORD` to set important values for the database. They make the configuration easier to change and help avoid putting passwords directly in the main settings. This makes the Compose file more organized and easier to manage.

Deploying Nextcloud in just a few minutes felt exciting because I was able to see a complete cloud storage system working. It was easier than I expected because Docker Compose handled the different containers for us. It also helped me understand how containers can work together.

Since Mission 1, my understanding of Cloud Computing has improved. Before, I only had a basic idea of what cloud computing was. Now, I understand more about containers, servers, databases, storage, and deployment. Each mission has helped me learn how these technologies are connected and used in real cloud systems.
