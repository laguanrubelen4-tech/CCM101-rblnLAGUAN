# Laboratory Reflection

This laboratory activity helped me better understand the basic parts of cloud infrastructure and how they work together. Among all the components, I believe the computer resource is the most important because it handles the processing needed to run applications and services. Without it, the other components, such as storage and networking, would not be very useful on their own.

Linux plays an important role in cloud computing because it is flexible, reliable, and lightweight. During this activity, I got hands-on experience using the Linux terminal. I practiced running commands, creating users and folders, managing files, and checking system information. These skills gave me a better idea of what it is like to work with a cloud environment.

I also learned why technical documentation is important before deploying infrastructure. It provides a clear guide about the system setup, requirements, and steps to follow. Good documentation can help prevent mistakes, make troubleshooting easier, and allow other people to understand and maintain the system.

Throughout the laboratory, I learned new skills such as navigating the Linux terminal, organizing files and folders, creating users, checking system details, and writing documentation using Markdown. I also became more comfortable using a cloud-based Linux environment and GitHub to organize my work.
