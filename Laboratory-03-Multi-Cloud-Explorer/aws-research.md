# 1. Amazon Web Services (AWS)

**Brief Overview:** AWS is a cloud platform from Amazon that provides computing, storage, databases, networking, and other cloud services.

**Global Infrastructure:** AWS has Regions and Availability Zones around the world to provide reliable and scalable cloud services.

**Cloud Management Console:** The AWS Management Console allows users to create, monitor, and manage AWS resources.

**Four Core Services:**

* Amazon EC2 – Virtual servers
* Amazon S3 – Cloud storage
* Amazon RDS – Managed databases
* Amazon VPC – Virtual networking

**Three Advantages:**

1. Highly scalable
2. Global availability
3. Wide range of services

**Typical Enterprise Use Cases:** Website hosting, data storage, database management, backup, disaster recovery, and application development.
