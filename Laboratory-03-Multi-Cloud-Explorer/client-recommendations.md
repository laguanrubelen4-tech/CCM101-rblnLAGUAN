
**Client A – Startup Company**

Recommended Platform: AWS
AWS is recommended because it provides flexible and scalable services suitable for startups with limited budgets. The company can start with smaller resources and scale as the application grows. Services include Amazon EC2, Amazon S3, and Amazon RDS.

**Client B – University**

Recommended Platform: Microsoft Azure
Azure is recommended because it integrates well with Windows Server, Microsoft 365, and Active Directory. This makes it easier for the university to migrate existing services to the cloud. Services include Azure Virtual Machines, Microsoft Entra ID, and Azure Blob Storage.

**Client C – AI Research Company**

Recommended Platform: Google Cloud Platform (GCP)
GCP is recommended because it provides strong Artificial Intelligence, Machine Learning, and high-performance computing capabilities. It offers tools for developing, training, and deploying AI applications. Services include Compute Engine, Vertex AI, and Google Kubernetes Engine (GKE).

**Client D – Global E-Commerce Company**

Recommended Platform: AWS
AWS is recommended because its global infrastructure can support customers from different parts of the world. Its scalable services can automatically handle changes in website traffic and demand. Services include Amazon EC2, Amazon Auto Scaling, and Amazon CloudFront.
