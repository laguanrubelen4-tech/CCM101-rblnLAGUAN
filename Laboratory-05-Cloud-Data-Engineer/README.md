# Laboratory 05 – The Cloud Data Engineer

## Mission Overview

In this laboratory activity, I was assigned to the Cloud Data Engineering Team at CloudNova Technologies. The mission focused on learning how cloud storage works and deploying an S3-compatible object storage server using MinIO and Docker.

The activity demonstrated how object storage can be used to store unstructured data such as images, videos, documents, and backups. I deployed MinIO in a KillerCoda Ubuntu Playground, accessed its web console, created a storage bucket, and uploaded a sample file.

## Objectives

* Differentiate between Block Storage, File Storage, and Object Storage.
* Deploy an S3-compatible Object Storage server using MinIO.
* Use Docker to run a cloud storage service.
* Access the MinIO Web Console using port forwarding.
* Create a storage bucket named `client-photos`.
* Upload a sample object to the bucket.
* Document cloud storage operations using Markdown.
* Expand my GitHub Cloud Computing portfolio.

## Completed Mission

The MinIO object storage server was successfully deployed using Docker. The MinIO Web Console was accessed through port `9001`, and the `client-photos` bucket was created successfully.

A sample file was uploaded to the bucket to verify that the object storage environment was working properly.
