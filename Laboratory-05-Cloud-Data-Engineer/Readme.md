
# Laboratory 05 - Cloud Data Engineer

## Mission Overview

Mission 5 focuses on cloud storage and the management of unstructured data. In this laboratory activity, MinIO is deployed using Docker as an S3-compatible Object Storage server. The system is used to create a storage bucket named `client-photos` and upload a test object to demonstrate how cloud applications can store user-uploaded images.

## Objectives

At the end of this laboratory activity, the following objectives were completed:

* Differentiate between Block, File, and Object Storage.
* Deploy an S3-compatible Object Storage server using MinIO and Docker.
* Access a cloud service through a web interface using port forwarding.
* Create a storage bucket and upload objects to the cloud.
* Document cloud storage operations using Markdown.
* Expand the GitHub Cloud Computing Portfolio with the completed laboratory activity.

## Tools Used

* **KillerCoda Playground** – Used as the Ubuntu/Docker cloud environment.
* **Docker** – Used to deploy and run the MinIO container.
* **MinIO** – Used as the S3-compatible Object Storage server.
* **Web Browser** – Used to access the MinIO Web Console.
* **GitHub** – Used to store and manage the Cloud Computing laboratory portfolio.
* **Markdown** – Used to document the laboratory activities and technical steps.

## Skills Learned

* Understanding the differences between Block, File, and Object Storage.
* Deploying an S3-compatible object storage server using Docker.
* Creating and managing Docker containers.
* Mapping container ports to access cloud services.
* Using environment variables to configure a container.
* Accessing a cloud storage management console through a web interface.
* Creating storage buckets in MinIO.
* Uploading and managing objects in an Object Storage bucket.
* Documenting technical procedures using Markdown.
* Organizing and maintaining a professional GitHub Cloud Computing portfolio.
