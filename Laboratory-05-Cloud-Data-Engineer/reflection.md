# Reflection

This laboratory activity helped me understand how object storage works and why it is useful for cloud applications. Object storage is better for storing millions of photos because it is made for storing large amounts of files such as images, videos, and documents. It can store many files without using a traditional hard drive system. It is also easier for applications to access and manage the stored files.

Docker made it easier to deploy the MinIO storage server because I did not need to install and configure everything manually. I only needed to run the Docker command provided in the activity. Docker created the MinIO container and allowed me to set the username, password, and ports. This made the deployment faster and easier to manage.

A bucket is a storage container used to organize objects in cloud storage. In this activity, I created a bucket named `client-photos`. I used this bucket to store the sample file that I uploaded. This helped me understand how files are organized in object storage.

Large companies can protect their data from being lost when a physical server crashes by keeping multiple copies of the data. They can also store the copies on different servers or locations. They may use backups, replication, and other systems that help keep the data safe and available even when one server has a problem.

My confidence in using the Linux command line is also growing. At first, I was not very familiar with Linux commands, especially Docker commands. After using commands like `docker run` and `docker ps`, I became more comfortable using the terminal. I learned that reading and understanding each command makes it easier to use Linux. This activity gave me more experience with Linux, Docker, MinIO, and cloud storage.
