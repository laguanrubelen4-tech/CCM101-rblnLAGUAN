

## The Cloud Operations Engineer REFLECTION 

In this laboratory activity, I learned the importance of monitoring and troubleshooting cloud applications. First, checking the host server's resources is important even if the containers are running perfectly because the server may still run out of RAM or disk space. When resources become insufficient, applications can become slow, stop working, or crash. Checking the server's condition helps prevent these problems before they happen.

Second, the `docker logs` command helps troubleshoot problems when a user cannot log in to a web application. By checking the logs, I can look for error messages, failed requests, or other issues that may explain the problem. These details help me understand what happened instead of guessing the cause.

Third, monitoring logs and monitoring metrics have different purposes. Logs show specific events and messages generated by an application, such as successful requests and HTTP 404 errors. Metrics show numerical information about performance, such as CPU usage, memory consumption, and network activity. Both are important because logs help identify what went wrong, while metrics help determine how well the application and container are performing.
