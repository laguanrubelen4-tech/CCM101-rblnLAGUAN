
## Security Audit Report 


## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users only the permissions they need to perform their assigned tasks. It is important for cloud user accounts because it helps prevent unauthorized access and reduces the possible damage if an account is compromised.

## 2. Attack Surface

The attack surface refers to all the possible entry points an attacker could use to access or exploit a virtual machine. These include open ports, running services, applications, and user accounts, so disabling unnecessary services and closing unused ports can help improve security.

## 3. Default Deny Policy

A Default Deny policy blocks all incoming network traffic unless a firewall rule specifically allows it. This is safer than blocking individual hackers because it automatically restricts unauthorized connections, including those from unknown sources, instead of requiring administrators to identify and block every possible attacker.
