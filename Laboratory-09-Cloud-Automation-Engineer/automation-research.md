
# Automation Research


## 1. Bash Script

A Bash script is a text file that contains Linux commands that run one after another to perform tasks automatically. The line `#!/bin/bash`, called the shebang, tells the operating system to use the Bash shell to execute the script. It helps automate repetitive tasks such as creating folders, managing files, and backing up data.

## 2. Variables

Variables are used to store values, such as folder paths, filenames, or dates, so programmers do not have to type the same information repeatedly. For example, `$BACKUP_DIR` stores the name or path of the folder where backup files will be saved. Using variables makes a script easier to read, update, and maintain because a value can be changed in one place.

## 3. Cron Job

A cron job is a Linux feature that automatically runs a command or script at a scheduled time or on a regular interval. It uses a time-based expression to determine when a task should run, such as performing backups every day at 2:00 AM. Cron jobs are essential for cloud operations because they automate routine maintenance, backups, and other repetitive tasks without requiring an administrator to run them manually.
