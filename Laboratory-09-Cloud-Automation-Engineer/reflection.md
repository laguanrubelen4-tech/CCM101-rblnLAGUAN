
# Reflection

Automation is critical when managing hundreds of cloud servers because it saves time, reduces repetitive manual work, and helps maintain consistency. Instead of configuring each server individually, administrators can use scripts to perform tasks such as backups, updates, and system maintenance. Automation also reduces human errors and allows IT teams to manage more servers efficiently.

However, automation also has potential dangers. A destructive typo in a script scheduled to run on 1,000 servers could delete important files, damage configurations, or interrupt services across many systems. This could cause data loss, downtime, and financial problems. To prevent these issues, scripts should be tested in a safe environment, reviewed carefully, and monitored before being deployed on multiple servers. Backups and proper access permissions are also important.

Writing a Bash script was different from creating a Docker Compose YAML file in Mission 6. A Bash script contains commands that execute tasks step by step, such as creating directories and compressing backup files. Docker Compose YAML, on the other hand, defines how containers and services should be configured and connected. Bash focuses on executing commands, while Docker Compose focuses on describing the desired container setup.

From Laboratory 1 to Laboratory 9, my understanding of Cloud Computing has improved significantly. I learned that cloud computing involves more than simply using online services. It also includes managing infrastructure, deploying applications, monitoring resources, securing systems, and automating repetitive tasks. Each laboratory helped me understand how different cloud technologies work together to provide reliable and efficient services.

Among the roles I explored, I enjoyed the Cloud Security Engineer role the most because it taught me the importance of protecting systems, controlling access, and limiting unnecessary open ports. I also appreciated learning automation because it showed me how scripts can simplify server management. Overall, these laboratories improved my technical skills and gave me a better understanding of the responsibilities of a cloud computing professional.
